# הודעות החשבון והאבטחה

13 תבניות בעברית וב־RTL, בסגנון הודעת ההרשמה שאושרה: כרטיס לבן, רקע בהיר, ירוק וזהב, טבלאות ו־CSS בתוך האלמנטים. רשימת הקבצים, הנושאים ומשתני Supabase נמצאת ב־`templates.json`.

כולל הרשמה, שחזור סיסמה, הזמנה, קישור כניסה, אישור שינוי דוא״ל, קוד אימות זהות ושבע התראות על שינויים בסיסמה, בדוא״ל, בטלפון, בדרכי הכניסה וב־MFA.

## תחזוקה ושחזור

- המקור: `scripts/build-auth-emails.mjs`. הפקה: `node scripts/build-auth-emails.mjs` משורש הפרויקט. הפקה מקומית אינה מעדכנת את Supabase אוטומטית.
- `original-templates.json` מכיל את הנושאים והתוכן שלפני העדכון, ללא פרטי משתמש או אסימונים אמיתיים. לשחזור יש להדביק את הנושא והגוף בעורך התבנית המתאימה ולשמור.
- המחולל מוודא שכל המשתנים המקוריים נשמרו. קישורי הפעולה משתמשים ב־`{{ .ConfirmationURL }}`, וקוד האימות ב־`{{ .Token }}`. אין להחליפם בקישור קבוע או באסימון אמיתי.
