# מסודרים 360 — חלופות זהות בדמו המקומי

היקף הפיתוח המקורי: דמו מקומי. בהמשך, ב־20.10.2026, המשתמש אישר פרסום לדמו הציבורי בלבד. גרסה זו נשלחת לתהליך GitHub Pages לאחר בדיקות; המערכת החיה אינה כלולה בפרסום.

## צפייה

לאחר `npm run build` ו־`npm run preview -- --port 5250 --strictPort`:

- גלריה: `http://127.0.0.1:5250/family360-preview/?brandlab=1`
- אפשר להוסיף `&brand=1` עד `&brand=5` לבחירה התחלתית.
- מכל חלופה אפשר לפתוח את מסך הבית או השאלון הפעילים.
- בורר הלוגו בסרגל ההדגמה מעדכן את הלוגו, הסמל בכותרת הדפדפן והחתימה בשאלון, בלי להחליף תפקיד או לאפס טופס.
- בגלריה, המערכת נשארת מותקנת אך מוסתרת. החזרה שומרת טיוטה ומיקום גלילה; מעבר מתפקיד אחר ללקוח משתמש באישור מעבר התפקיד הקיים.

## החלופות

1. **מדרגות לתמונה מלאה** — שישה אריחים ומסגרת פתוחה. הכיוון המומלץ לקשר עם מותג מסודרים.
2. **התמונה השלמה** — ארבע פינות עם מרכז נחושתי.
3. **דרך של ביטחון** — רצועה אדריכלית רציפה בשלושה מפלסים.
4. **חיבור משפחתי** — שתי קשתות משתלבות, כיוון אנושי ורך.
5. **מבט 360** — מסגרת מעגלית ואריחים מסודרים בתוכה.

לכל חלופה SVG בהיר, כהה ובצבע אחד, בנפרד כלוגו מלא וכסמל. קובצי המקור ב־`public/brand/`.
האותיות הן קווי מתאר של Assistant, לפי רישיון OFL המצורף. אין תלות בגופן חיצוני ואין העתקה של קובצי הגופן הפרטיים באתר ההשראה.
שחזור הקבצים: `python scripts/generate-brand.py` עם Python ו־fontTools; אלה כלי הכנה בלבד, לא תלויות של האתר.

- בחירת המיתוג בלבד נשמרת ב־localStorage. נתוני לקוח אינם נשמרים שם. חסימת האחסון אינה מונעת שימוש בבורר.
- נשמרו שדות, פעולות, סינונים, הרשאות ותהליכי שמירה ושליחה.

## אימות

- בניית TypeScript ו־Vite.
- 143 בדיקות יחידה ב־20 קבצים.
- בדיקות הדפדפן הקיימות: demo, ux, professional-admin, client-intake, chapter-process, client-workspace, client-folio.
- `npm run test:branding`: חמש חלופות × מסך בית ושאלון × מחשב, נייד ונייד צר; שמירת טיוטה בהחלפה ובניווט; פוקוס מקלדת; בחירה לאחר רענון; אחסון חסום; ערך חלופה לא תקין; טעינת SVG; גלישה אופקית; שגיאות JavaScript ובקשות חיצוניות.
- צילומי הבדיקה ודוחות JSON ב־`test-results/branding/`; נבדקו חזותית הגלריה, מסכי הבית והשאלון וייצוגי נייד, וכן מסך ניהול.
- מגבלת אימות: אלו בדיקות דפדפן מקומי ב־Chromium עם נתוני דמו. לא בוצע אימות במכשיר פיזי, מול שרת חי או של חיוב/משלוח/אחסון אמיתי.
- אזהרת הבנייה הקיימת על bundle מעל 500KB נשארת; אינה שגיאת בנייה.

## עדכון הכיוון הנבחר

לפי סמל הרפרנס שבחר המשתמש, חלופה 5 עודכנה למעגל פתוח עם מקטע נחושת נפרד ושלושה ריבועים מדורגים. הקומפוזיציה אנכית: סמל, מסודרים 360, ועושים לך סדר בכסף. כל האותיות, לרבות הסלוגן, הן קווי מתאר ב־SVG. הגרסאות בהיר/כהה/צבע אחד נשמרו, והארבע האחרות נשארות להשוואה.

נוספה תצוגה מרכזית לוגו חדש בראש הגלריה. ברירת המחדל החדשה היא חלופה 5; קישור מפורש עם brand עדיין יכול לבחור אחרת. בחירת הלוגו משתמשת במפתח mesudarim360:brand:stacked, בלי לשמור מידע לקוח. הרקע הכהה בגלריה ובתפריט מורכב מגוני יער ובקבוק עם שכבות אלכסוניות עדינות, לפי קובצי ה־PDF שסופקו.

בדיקות העדכון: build, test:branding, test:client-folio ובדיקה חזותית של גרסה כהה ובהירה, מסך הבית והשאלון בנייד. כתובת הדמו הציבורי נשארת https://huxhkuh.github.io/family360-preview/ . תוכן המיתוג המעודכן מתפרסם באמצעות תהליך הבדיקות והפרסום הקיים, בתוספת test:branding.
