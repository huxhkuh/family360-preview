# Rig הקמע — מסודרים 360
עודכן: 26.10.2026. בחירת המשתמש: חליפה ללא עניבה.

## מצב
Rig השכבות מחובר ל-HeroGaze בדף הבית. יש מעקב רציף, תנועת ראש קטנה, מצמוץ, Idle למכשיר מגע ומצב מופחת תנועה. הפרסום אושר ב-26.10.2026 ומבוצע באמצעות תהליך GitHub Pages הקיים, לאחר הצלחת בדיקותיו. טרם נבדקו Firefox, Safari או מכשיר נייד פיזי.

## הארכיטקטורה
איור יחיד ושכבות שנגזרו ממנו, לא סדרת פריימים. הגוף והצווארון מצוירים בשכבה קבועה. הראש המקורי כולל הכיפה והשיער נע כיחידה קשיחה, עם חפיפה נסתרת מתחת לצווארון. האישונים זזים בתוך מסכות; העפעפיים נחשפים באמצעות מסכה רציפה. אין crossfade בין פנים, אין מתיחת הראש ואין אנימציית גוף.

| אפשרות | התאמה | מגבלה |
|---|---|---|
| Rive | סביבת authoring טובה, raster ו-mesh, state machine | דורש הכנת שכבות וקובץ riv; runtime נוסף; לא משחזר אזורים מוסתרים |
| Live2D Cubism | מתאים לסיבוב פנים משמעותי ופרלקסה | דורש הפרדת חומרים, ציור השלמות, authoring ורשתות; רישוי הפצה |
| SVG שכבות — נבחר | שומר על טקסטורות האיור, מסכות מדויקות, ללא runtime נוסף | הטיה קשיחה קטנה בלבד, לא סיבוב ראש תלת־ממדי |

הבחירה מותאמת למבט ולתנועת הראש הקטנה שהתבקשו. אם תידרש הפניית פנים ממשית לצדדים, יש להכין מודל Cubism או תלת־ממד; אין לדמות זאת במתיחת הפנים.

## מימוש
- src/customer/mascot/artwork.ts: מדידות, מסכות, pivot, טווחי תנועה ועקומות העפעפיים.
- src/customer/mascot/motion.ts: בקר עצמאי, spring מרוסן קריטית, הגבלות מהירות, מצמוץ אקראי ו-Idle.
- src/customer/mascot/MascotRig.tsx: renderer, decode ובדיקת מידות לפני חיבור אטומי, RAF יחיד, refs ללא React render בכל פריים, ניקוי listeners, IntersectionObserver ו-visibilitychange.
- ResizeObserver וגלילה מרעננים מטריצת מיקום. יעד האישונים מפוצה עבור תנועת הראש באמצעות הטרנספורמציה ההפוכה.
- הפחתת תנועה עוצרת RAF ומאפסת את הראש והעיניים. כשל בשכבה משאיר איור שלם; כשל גם באיור החליפה חוזר ל-welcome.png המקורי.
- נשימה כבויה כדי לשמור על הגוף יציב.

## מקורות הנכסים
לא נוצרו תמונות נוספות במהלך חיבור ה-Rig. נעשה שימוש ביצירות שכבר הוכנו דרך ממשק ChatGPT, לפי בקשת המשתמש.
- master.png: חליפה ללא עניבה, קובץ תקין שנמצא בהורדות ושנבדק חזותית מול המקור.
- head.png והאישונים: חיתוכים ללא אובדן מתוך public/homepage/welcome.png המקורי.
- sclera.png ו-lids.png: חיתוכים מקומיים מהשלמות לובן ועפעפיים שנוצרו קודם. אין שימוש בתמונות המלאות שלהן כפריימים.
- neck.png: חיתוך מתוך ההשלמה שנוצרה קודם לצוואר שמאחורי הראש.
- scripts/extract-rig-plates.ps1 משחזר את החיתוכים. המסכות נשמרות בקוד SVG, ולא נצרבות באיור.
- שבעה קובצי PNG ב-public/companion/rig, כ-0.93MB יחד. לא נטענים שמונת כיווני המבט הישנים.

מקורות העבודה ב-design/mascot-rig וב-design/mascot-wardrobe. עמוד בדיקה: design/mascot-rig/preview.html. הוא כולל מצבי מבט, סגירה חלקית ומלאה, הגדלה ורקע כהה; אינו חלק מניווט האתר.

## אימות שבוצע
- עשר בדיקות Vitest של בקר התנועה עברו, כולל 30/60/144Hz בחישוב, היפוכים, מצמוץ, Idle, חזרה למנוחה ופיצוי יעד עיניים.
- npm run build עבר. אזהרת chunk יישום מעל 500kB עדיין קיימת.
- בדיקה ב-Chromium באמצעות CUA/CDP, בדף הבית בפועל: מסלולים מעגליים והיפוכי צד, יציאה מהחלון, התייצבות לאחר עצירה.
- פיקסלי אזור הגוף/הידיים/הרגליים נשארו זהים לפני ואחרי התנועה. שכבת הראש יחידה.
- בהפחתת תנועה כל פיקסלי הקמע נשארו זהים לאחר תנועת סמן.
- אמולציית מובייל 390×1100 עם מגע וללא fine pointer הפעילה Idle; צילום מלא נבדק חזותית.
- חסימת head.png הציגה איור חליפה שלם ללא SVG חלקי. חסימת כל נכסי ה-Rig הציגה את המקור השלם. החסימות בוטלו לאחר הבדיקה.
- נבדקו בהגדלה: ניטרלי, קצוות תנועה, חצי מצמוץ, סגירה מלאה ורקעים בהיר/כהה. תוקנו תפר בצוואר וקווי מתאר כפולים בעיניים.
- מדגם מקומי של 120 פעימות RAF: חציון 16.7ms, אחוזון 95 כ-16.8ms, אפס מרווחים מעל 50ms. זו מדידה מקומית, לא הבטחת ביצועים לכל מכשיר.
- לפני הזרקת תקלות טעינה לא נרשמו שגיאות console בדף שנבדק.
- לפני הפרסום עברו כל 308 בדיקות היחידה. scripts/check-hero-gaze.mjs עבר מול הבנייה המקומית במחשב, אמולציית מובייל והפחתת תנועה, כולל השוואת פיקסלי הגוף, עצירת תנועה ותצוגת fallback בכשל שכבה.
- scripts/check-customer-journey.mjs עבר מול הבנייה המקומית ברוחב 1440 ו-390, כולל הרשמה, תשלום מדומה, שאלון, חזרה לטיוטה ומסלול הפניה; ללא שגיאות JavaScript.

## בדיקות שעדיין אינן מאומתות
Safari/Firefox, חומרת מובייל אמיתית, throttling על מכשיר חלש, רענון 144Hz פיזי ובדיקה אוטומטית של unmount/remount. בדיקות מספריות אינן מחליפות הערכה אנושית של טבעיות התנועה.
