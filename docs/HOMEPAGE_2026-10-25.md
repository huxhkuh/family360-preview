# דף בית נוסף בדמו הקיים

דף הבית שולב בגרסה המפורסמת המעודכנת של family360-preview, על בסיס a94413e. הוא אינו מחליף את ממשק המערכת או את עיצובו.

- כפתור ״דף הבית״ בסרגל הדמו; קישור ישיר `#welcome`.
- שימור המסך, החיפוש ומצב הרכיבים במעבר לדף הבית וחזרה.
- לוגו באמצעות משאב המותג הקיים; שלושה איורים שסיפק המשתמש.
- הטקסט בדף הבית מוגדל פי שניים; CSS הדף מופרד ומוגבל למחלקות הדף.
- אין חיבור לסליקה. פירוט החבילה במחיר 490 ש״ח ממתין לאישור.

אימות מקומי: בנייה, 204 בדיקות יחידה, בדיקת הדמו בארבעה תפקידים במחשב ובנייד ובדיקת homepage ייעודית שמוודאת גם את שימור החיפוש והעיצוב במערכת. הוספה אותה בדיקה לתהליך הפרסום.

הדמו ההיסטורי family360-demo אינו בסיס לפיתוח הנוכחי. הקישור אליו יופנה לדמו זה כדי למנוע כניסה בטעות למערכת ההיסטורית.
