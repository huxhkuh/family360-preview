# יישום החלטות השאלון והמסמכים — דמו מקומי

מסמך זה מעדכן את ההחלטות שהיו פתוחות בדוחות הניסוחים וה־UX הקודמים. לא בוצעו פרסום, push או שינוי במערכת החיה.

## החלטות שיושמו

- הכנסה מעסק: רווח חודשי ממוצע לאחר הוצאות העסק ולפני מסים. סכום שלא נמסר מופיע לנציג להשלמה.
- מינוס ואשראי: יתרה שלילית בפועל, כולל חריגה, לצד שימוש במסגרת המאושרת. ההסבר מבהיר שאין לחבר שוב את הסכומים.
- נכסים ומשכנתאות: פרטי הנכס והמשכנתא הראשונים נשמרו במפתחות הקיימים. נוספו רשימות לנכסים ולמשכנתאות נוספים וקישור תיאורי לנכס; אפשר לדווח גם על נכס בבעלות משפחה שגרה בשכירות. נתוני ספירה היסטוריים נשארים זמינים אם קיימים.
- מועד משכנתא: שנה, חודש ושנה או תאריך מלא; תאריכים מלאים קיימים נשמרים. תאריך לא תקין או עתידי מסומן לתיקון.
- רב־קו: שתי שאלות נפרדות על הנחה פעילה ועל רצון בבדיקת הנחה. תשובה היסטורית נשמרת בנפרד ולא מקבלת משמעות חדשה.
- חסכונות: נוספו מטרות לבדיקה ולשיפור, לצד ״אין״ ו״לא יודעים״. מטרות הבדיקה מופיעות לנציג.
- קצבאות: אפשרות ״קצבה אחרת״ עם פירוט; ״לא מקבלים״ ו״לא יודעים״ אינן נבחרות יחד עם קצבאות אחרות.
- בן/בת הזוג: הכותרות ואפשרויות התעסוקה עודכנו. מפתחות המידע הקיימים נשמרו.
- טלפון: הטלפון בתיק ממלא את השאלון בתחילה. שינוי תקין שנשמר בשאלון מעדכן את התיק. שינוי בתיק מעדכן את השאלון. מספר לא תקין נשמר בטיוטה בלבד ואינו מחליף טלפון תקין. טיוטה פתוחה אינה נדרסת בעת עדכון מקביל.
- תעודת זהות: הוסבר השימוש להכנת הפנייה לסוכן הביטוח לצורך המסלקה, בנפרד מצילום התעודה ומהרשאה חתומה.

## מסמכים

דפי חשבון אינם מוצעים. תעודת זהות בנקאית מוצעת אם דווח על חשבון, ורק אם יש ברשות הלקוח.

לרשימת ההכנה נוספו תעודת זהות וספח לכל אדם רלוונטי, הרשאה נפרדת למסלקה, חשבונות ארנונה וחשמל, ודוח פנסיה שנתי אם סומנה פנסיה. תלושי שכר, שומת מס, חוזה שכירות, דוח יתרות משכנתא ופירוט הלוואות נשארו לפי התשובות.

כל פריטי ההכנה הם רשות ואינם חוסמים שליחת שאלון. בוטלה יצירת בקשת פנסיה אוטומטית רק כדי להדגים מסמך חסר. לאחר שליחה המצב הוא ״ממתין לבדיקת נציג״. יכולת הנציג להוסיף בקשה פרטנית בהמשך נשמרה ומובחנת מרשימת הרשות.

הרשאה נוצרת כפריט מסוג חתימה, ולא כקובץ שהועלה. לא תועדה הסכמה מדומה ולא בוצעה העברה לסוכן. נדרש עדיין נוסח ההרשאה של הסוכן ופרטי מקבל ההרשאה והיקפה לפני הפעלת החתימה בפועל.

## בירור עם הנציג

בסקירת התיק ובהקשר המשפחה בזמן השיחה נוספה רשימת נושאים מהשאלון: תשובות שליליות מפורשות, ״אין״, ״לא יודעים״, מידע חלקי, סכומים שסומנו להשלמה ומטרות בירור. השאלה, הפרק והתשובה המקורית מוצגים לצד מקום לסיכום השיחה. התיעוד אינו משנה את תשובת הלקוח. שינוי תשובה מחייב בירור מחדש; הערות הצוות אינן נחשפות ללקוח או לבעל מקצוע.

## אימות

- `npm run build`: עבר; נותרה אזהרת גודל חבילה קיימת (מעל 500KB).
- `npm test`: כל 180 הבדיקות ב־23 קבצים עברו, לרבות בדיקות חדשות של שמירת טלפון, התנגשויות גרסאות, תנאים, תאריכים, בלעדיות אפשרויות, רשות והרשאות גישה.
- `npm run test:client-decisions`: עבר במחשב וברוחב 390 ו־320 פיקסלים; מילוי מלא, מספר נכסים ומשכנתאות, טלפון, מסמכים, שליחה, תיעוד נציג ופתיחה מחדש אחרי שינוי תשובה.
- `npm run test:client-copy`, `npm run test:companion`: עברו במחשב ובשני גדלי נייד.
- `npm run test:client-focus`, `npm run test:chapter-process`: עברו במחשב, בטאבלט ובשני גדלי נייד.
- `npm run test:client-intake`: עבר במחשב, בטאבלט ובנייד, כולל בקשה פרטנית מפורשת של נציג, דחייה ושליחה מחדש.
- `npm run test:ux`: תהליכי הנציג, עריכה, משימות, טיוטות והרשאות עברו במחשב ובנייד; בדיקות זרימת העבודה עברו גם בטאבלט.
- צילומי המסמכים במחשב וברוחב 390 ו־320 נבדקו חזותית. לא נמצאו גלישה אופקית או שגיאות JavaScript במסלולים שנבדקו.

תיעוד הרצות וצילומים: `test-results/client-decisions`, `client-copy`, `client-focus`, `client-intake`, `chapter-process`, `companion`.

## גבולות האימות

הדמו משתמש בנתונים מדומים ובקבצי דוגמה. לא נבדקו תשלום אמיתי, העלאה לשרת, שמירה לאחר רענון או חיבור לסוכן/מסלקה. כללי החתימה וההעברה בפועל ממתינים לנוסח ולהגדרת התהליך עם הסוכן.
