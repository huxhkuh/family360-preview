# פריסת סביבת הבדיקה בכתובת הקיימת

ב־26.10.2026 המשתמש ביקש במפורש לפרוס ב־`family360.pages.dev`, לאחר שהובהר כי זהו פרויקט Pages הקיים. הובהר לפני הפריסה שגם `mesudarim360.co.il` ו־`www.mesudarim360.co.il` מחוברים לאותה פריסה.

הממשק מציין סביבת בדיקה ללא חיוב. הקוד נשאר בענף `codex/cloudflare-production-migration`. הפריסה מכוונת לענף הפרסום המוגדר בפרויקט, `codex/agent-invitations`, בלי לשנות את ענף Git המקומי ובלי push.

הפריסה המאומתת כעת: `b78dc945-7f16-4d92-a9dc-b2e71899b330`, מצב `success`. דף הבית, קובץ JavaScript הראשי ו־health החזירו 200 לאחר הפריסה הסופית. טופס ההרשמה נפתח בדפדפן; צילום מקומי מוחרג מ־Git: `artifacts/live/family360-signup.png`.

## ניתוב

- `/api/*` ו־`/health` עוברים דרך Pages Worker אל service binding בשם `STAGING_API` שמצביע על `mesudarim360-api-staging`.
- יתר הנתיבים הם קבצים סטטיים. הגדרות `_headers` נשארות בתוקף עבורם.
- ה־API מבצע את בדיקות האימות וההרשאות המקוריות. מתאם Pages לא מוסיף הרשאות או אסימונים. אין יעד proxy שרירותי.
- ה־API מתיר את שלושת המקורות של הפרויקט, בנוסף למקור staging הקודם ול־localhost. R2 נשאר פרטי; מסד הנתונים הוא `mesudarim360-staging` בלבד.
- `fail_open=false` בשתי סביבות Pages מונע נפילה לשירות סטטי כשהפעלת Functions אינה אפשרית.
- build עם `VITE_API_URL=same-origin` יוצר את `_worker.js` ו־`_routes.json`. בלי ערך זה נשמר מסלול ה־API החיצוני הקודם.

## שחזור הממשק הקודם

פריסת הייצור הקודמת נשמרה ב־Cloudflare: `4183521a-a45b-4fb6-badb-ea8f4a0836d5`.

לאחר החלטה לחזור, ניתן לבצע rollback דרך Cloudflare Pages או `POST /accounts/{account_id}/pages/projects/family360/deployments/4183521a-a45b-4fb6-badb-ea8f4a0836d5/rollback`.

פעולה זו מחזירה את הפריסה הקודמת לכל שלוש הכתובות. היא אינה מוחקת את נתוני staging או משחזרת מסד נתונים. לפני שינוי נוסף יש לתעד את הפריסה הקנונית העדכנית ולהשאיר את משאבי הבדיקה קיימים. לא בוצע תרגול rollback חי משום שהיה מחליף את הממשק שהמשתמש ביקש כעת.

## אימות

339 בדיקות עברו; build עבר. בדיקת workerd מקומית כוללת גם העברת בקשות דרך service binding, חסימת RPC אנונימי, סירוב למקור זר וניתוב קבצים סטטיים. בבדיקת HTTP חיה דרך `family360.pages.dev` אומתו 200 לדף ול־health, 401 ל־RPC ולהורדת מסמך ללא אסימון, 204 ל־preflight מורשה ו־403 למקור לא מורשה. בדיקות Auth עם דוא״ל אמיתי, MFA, כל התפקידים וגיבוי ענן מלא נותרו פתוחות.
