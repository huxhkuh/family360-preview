# המלווה של מסודרים — קובצי הדמות

שמונה פוזות נפרדות מתוך התמונה שסופקה, עם ערוץ השקיפות המקורי:

- welcome — פתיחה
- explain — הסבר
- pause — עצירה; נשמרה בערכה ואינה מוצגת כבקשת המתנה
- document — בקשת מסמך
- later — השלמה בהמשך
- success — אישור פעולה שהצליחה
- review — תיקון מסמך
- complete — סיום; זמינה לשימוש עתידי

קובצי PNG מלאים לשימוש עיצובי, ועותקי WebP ללא אובדן לאתר.
`companion-poses.zip` מכיל את שמונת קובצי ה־PNG.
הדמות אינה SVG: האיור המקורי נשמר. רכיבי React ב־src/companion
מנהלים את ההקשר, ההסברים, הפעולות והחלפת הפוזות.
המסגור בממשק מציג את פלג הגוף העליון; בקבצים נשמרת הדמות המלאה.

כללי הכנת המסמכים הם הדגמה לפי הדוגמאות שכבר קיימות במערכת.
הם אינם הגדרה סופית של דרישות אישיות. הדמו מצרף דוגמה בלבד,
ללא העלאת קובץ, שליחת הודעה, חיבור לסליקה או פנייה לנציג אמיתי.
העדפת ״אשלים בסוף״ נשמרת במעבר בין מסכים באותו דמו ונמחקת ברענון.
